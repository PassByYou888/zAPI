# zAPI Binary 目录动态库说明

本目录包含了 **zAPI** 和 **zIPC** 项目所需的运行时动态链接库（DLL），以及 **mimalloc** 高性能内存分配器库。所有 DLL 均依赖 **Microsoft Visual C++ 2022 Redistributable**（VC++ 运行库），请在使用前确保已安装对应的运行时环境。

---

## 📦 文件清单与说明

### 🔷 mimalloc 内存分配器系列

| 文件名 | 架构 | 作用 | 来源 |
|--------|------|------|------|
| `mimalloc32.dll` | x86 (32-bit) | **mimalloc 核心库** – 微软开源的高性能内存分配器，提供线程局部缓存、低碎片、高吞吐等特性，被 zAPI 和 zIPC 内部使用。 | [Microsoft mimalloc](https://github.com/microsoft/mimalloc) |
| `mimalloc64.dll` | x64 (64-bit) | 同上，64 位版本。 | 同上 |
| `mimalloc-redirect32.dll` | x86 | **mimalloc 重定向库** – 用于将程序中的 `malloc`/`new` 调用重定向到 mimalloc，无需修改源码即可启用。 | 同上 |
| `mimalloc-redirect.dll` | x64 | 同上，64 位版本。 | 同上 |

### 🔷 zIPC 进程间通信库

| 文件名 | 架构 | 作用 | 来源 |
|--------|------|------|------|
| `z_ipc_32.dll` | x86 (32-bit) | **zIPC 核心库**（Release 版）– 基于共享内存 + 消息队列的高效进程间通信库，支持 RPC 调用和通知机制，用于同一主机上多进程通信。**延迟 < 1ms，吞吐 10,000+ 请求/秒**。 | [zIPC](https://github.com/PassByYou888/zIPC) |
| `z_ipc_64.dll` | x64 (64-bit) | 同上，64 位 Release 版。 | 同上 |
| `z_ipc_32d.dll` | x86 | **zIPC Debug 版** – 包含调试符号和额外检查，用于开发调试阶段。**不建议在生产环境中使用**。 | 同上 |
| `z_ipc_64d.dll` | x64 | 同上，64 位 Debug 版。 | 同上 |

> **关于 zIPC Debug 版（带 `d` 后缀）**：Debug 版体积较大（约 1.6~1.9 MB），包含更多运行时检查和调试信息，速度略慢，仅供开发调试。生产环境请使用 Release 版（约 215~235 KB）。

### 🔷 zAPI Hub 核心 RPC 库

| 文件名 | 架构 | 作用 | 来源 |
|--------|------|------|------|
| `z_api_hub32.dll` | x86 (32-bit) | **zAPI Hub 核心库**（Release 版）– zAPI 跨语言 RPC 框架的中心调度组件，负责服务注册、请求路由、负载均衡等。**支持 10+ 种语言互调**。 | [zAPI](https://github.com/PassByYou888/zAPI) |
| `z_api_hub64.dll` | x64 (64-bit) | 同上，64 位 Release 版。 | 同上 |

> **注意**：zAPI Hub 核心库运行时依赖 `z_ipc_64.dll`（或 `z_ipc_32.dll`），两者必须保持位数一致。例如，使用 64 位 `z_api_hub64.dll` 时，必须同时配备同目录下的 `z_ipc_64.dll`。

## ⚙️ 系统要求

- **操作系统**：Windows 7 SP1 及以上（包括 Windows 10/11、Server 2012+）
- **运行时依赖**：**必须安装 Visual C++ 2022 Redistributable**
  - 32 位应用需安装 `vc_redist.x86.exe`
  - 64 位应用需安装 `vc_redist.x64.exe`
  - 如果同时使用两种架构，请分别安装两个版本。
- **安装方式**：直接双击对应的 `.exe` 文件，按向导完成安装。

> **注意**：如果您的系统已安装了 Visual Studio 2022 或更高版本的 C++ 工具集，则可能无需单独安装 Redistributable，但为了确保部署兼容性，建议在目标机器上执行安装。

## 📁 部署指南

- 将这些 DLL 放置在可执行文件**同目录**下，或添加到系统 `PATH` 环境变量中。
- **关键依赖关系**：
  - `z_api_hub64.dll` 需要 `z_ipc_64.dll` 和 `mimalloc64.dll`
  - `z_api_hub32.dll` 需要 `z_ipc_32.dll` 和 `mimalloc32.dll`
  - 如果您使用的是 zAPI 的 Debug 构建版本（通常不对外发布），请使用对应的 `z_ipc_*d.dll`。
- Debug 版本（带 `d` 后缀）仅用于调试，**不建议在生产环境中使用**。
- 如果您在开发环境中使用了 **Delphi** 或 **Free Pascal**，对应的绑定单元（如 `Z.IPC.Helper`、`mimalloc4p`）会自动加载这些库。

## ❓ 常见问题

**Q：运行时提示“找不到指定的模块”或“无法启动此程序”怎么办？**

A：请确认已安装对应的 VC++ Redistributable（双击运行 `vc_redist.x64.exe` 或 `vc_redist.x86.exe`），并检查 DLL 是否与应用程序的位数（32/64）匹配。

**Q：这些 DLL 是否开源？**

A：是的，所有底层库均为开源项目（MIT 或 BSD 风格许可证），具体可查阅上方仓库链接。

**Q：Debug 版和 Release 版有何区别？**

A：Debug 版（带 `d` 后缀）包含更多运行时检查和调试信息，体积较大、速度略慢，仅供开发调试；Release 版经过优化，适合生产环境。

**Q：`z_api_hub64.dll` 和 `z_ipc_64.dll` 必须一起使用吗？**

A：是的。zAPI Hub 核心库依赖 zIPC 进行进程间通信，两者必须保持位数一致并放在同一目录下。

**Q：`mimalloc-redirect.dll` 是做什么的？**

A：它是一个“重定向”库，可以将程序中对标准 `malloc`/`new` 的调用无缝切换到 mimalloc。如果您不使用它，zAPI/zIPC 也会通过自身绑定直接调用 mimalloc，所以 `mimalloc-redirect` 是**可选组件**。
