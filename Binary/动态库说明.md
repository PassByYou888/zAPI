# Binary 目录动态库说明

本目录包含了 **zAPI** 跨语言 RPC 框架及其依赖组件的所有运行时动态库。所有 DLL 均来自 **PassByYou888** 作者的开源项目。

---

## 📦 文件清单

### 核心库

| 文件名 | 说明 | 来源仓库 |
|--------|------|----------|
| `z_api_hub64.dll` | zAPI 核心库（64位） | [zAPI](https://github.com/PassByYou888/zAPI) |
| `z_api_hub32.dll` | zAPI 核心库（32位） | [zAPI](https://github.com/PassByYou888/zAPI) |

zAPI 核心库是跨语言 RPC 框架的主入口，负责服务注册、请求路由、负载均衡等。

### IPC 进程通信库

| 文件名 | 说明 | 来源仓库 |
|--------|------|----------|
| `z_ipc_64.dll` | zIPC 核心库（64位 Release 版） | [zIPC](https://github.com/PassByYou888/zIPC) |
| `z_ipc_32.dll` | zIPC 核心库（32位 Release 版） | [zIPC](https://github.com/PassByYou888/zIPC) |
| `z_ipc_64d.dll` | zIPC 核心库（64位 Debug 版） | [zIPC](https://github.com/PassByYou888/zIPC) |
| `z_ipc_32d.dll` | zIPC 核心库（32位 Debug 版） | [zIPC](https://github.com/PassByYou888/zIPC) |

zIPC 是基于共享内存的高效进程间通信库，同机延迟 < 1ms，吞吐 10,000+ 请求/秒。**Debug 版（带 `d` 后缀）仅供开发调试使用，生产环境请使用 Release 版。**

### mimalloc 内存分配器

| 文件名 | 说明 | 来源仓库 |
|--------|------|----------|
| `mimalloc64.dll` | mimalloc 核心库（64位） | [mimalloc4p](https://github.com/PassByYou888/mimalloc4p) |
| `mimalloc32.dll` | mimalloc 核心库（32位） | [mimalloc4p](https://github.com/PassByYou888/mimalloc4p) |
| `mimalloc-redirect.dll` | 重定向库（64位） | [mimalloc4p](https://github.com/PassByYou888/mimalloc4p) |
| `mimalloc-redirect32.dll` | 重定向库（32位） | [mimalloc4p](https://github.com/PassByYou888/mimalloc4p) |

mimalloc 是微软开源的高性能内存分配器，zAPI 依赖它获得低碎片、高吞吐的多线程内存管理能力。重定向库用于将标准的 `malloc`/`new` 调用无缝切换到 mimalloc。

## 🚀 使用方法

### 方式一：配置系统 PATH（推荐）

将本目录的**完整路径**添加到系统 `PATH` 环境变量中，这是**最省事、最推荐**的使用方式：

1. 打开 **系统属性** → **高级** → **环境变量**
2. 在 **系统变量** 或 **用户变量** 中找到 `Path`，点击 **编辑**
3. 点击 **新建**，粘贴本目录的完整路径（例如 `D:\git\zAPI\Binary`）
4. 点击 **确定** 保存，**重启命令行窗口**生效

配置后，任何语言绑定的程序都能自动找到这些 DLL，无需复制到每个项目目录。

### 方式二：复制到项目目录

将需要的 DLL 复制到可执行文件的同目录下。注意保持位数一致（32位应用用 32 位 DLL，64位应用用 64 位 DLL）。

## ❓ 常见问题

**Q：运行时提示“找不到指定的模块”？**

A：请确认：
1. 已安装对应的 VC++ Redistributable（双击运行 `vc_redist.x64.exe` 或 `vc_redist.x86.exe`）
2. DLL 已配置在 `PATH` 中，或已复制到可执行文件目录
3. DLL 位数与应用程序匹配（64位应用用 `*64.dll`，32位应用用 `*32.dll`）

**Q：z_ipc_64d.dll 和 z_ipc_64.dll 有什么区别？**

A：带 `d` 后缀的是 Debug 版，包含调试符号和额外检查，仅供开发调试。生产环境请使用 Release 版。

**Q：mimalloc-redirect.dll 是必须的吗？**

A：不是。zAPI 和 zIPC 通过自身绑定直接调用 mimalloc，重定向库是可选组件，仅在需要将第三方库的 `malloc`/`new` 调用也切换到 mimalloc 时才需要。
